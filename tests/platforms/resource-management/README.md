# 资源管理平台

本目录独占资源管理平台的页面对象、元素定位、数据工厂和 P0 用例。`locators/` 只声明页面元素，`pages/` 只编排操作与断言。

已确认入口路径为 `/resource-platform/index`，页面就绪态为“文件夹目录”可见。`P0-RESOURCE-01` 验证用户从门户卡片进入资源列表页。后续资源入库、目录、数据圈选和系统管理操作必须继续在本目录内维护。

业务 P0 使用共享 SSO Fixture 的 `authenticatedPage`，不得重复填写账号密码。新增资源入库、创建目录等写入用例时，必须注入 `dataScope`，并在资源创建后立即登记平台内清理。
